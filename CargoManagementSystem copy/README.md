You: Open http://localhost:5000/swagger\n2. Browser: Shows gateway Swagger UI\n3. Gateway: Loads swagger.json from all 8 services\n4. You: Select service from dropdown\n5. Gateway: Shows that service's API endpoints\n6. You: Click \"Try it out\" on endpoint\n7. Browser: Sends request to gateway\n8. Gateway: Routes to correct service (port 5001-5008)\n9.
